## 📖 Overview

A comprehensive full-stack multi-package web application built to integrate Google's advanced Gemini AI capabilities seamlessly into a responsive user interface, utilizing a modular markdown template system to dynamically inject custom domain knowledge into system prompts.

---

## ✨ Features

* *💬 AI Chat Interface:* Real-time conversational streaming and prompt handling.
* *💻 Frontend Client:* User-friendly, modern interface styled with Tailwind CSS.
* *🛠️ Backend API:* Robust Node.js & Express server handling secure API communication with Google GenAI.

---

## 🛠️ Tech Stack & Libraries

* *🎨 Frontend:*
  * React, Vite
  * Tailwind CSS, Lucide React (Icons)
  * React Hook Form, Axios
* *🔒 Backend & Security:*
  * Node.js, Express
  * Google GenAI SDK (@google/genai)
  * Dotenv, Zod

---

## 🚀 Deployment & Infrastructure

* *🌐 Frontend Client:* Deployed and hosted on *Vercel* with continuous integration from GitHub.
* *⚙️ Backend API:* Hosted as a web service on *Render*, handling secure Express endpoints and file-based prompt rendering.
